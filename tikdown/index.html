04 ABOUT / SPEC

WHAT THIS
TOOL IS.

TikDown (RAWGRAB utility 001) is an independent underground web tool: a thin honest client over a maintained extraction provider. It shows only what the provider returns — watermarked video, unwatermarked video and audio only when the provider supplies them — and says so when something is unavailable.

FEATURESTATUS
URL validation (host + video-path allowlist, trim, Enter, no double-submit)FUNCTIONAL
Live lookup via TikWM API (no key) + official TikTok oEmbed fallbackFUNCTIONAL — needs network; provider rate limits apply
Provider adapter: resolveVideo / getDownloadOptions / getProviderStatusFUNCTIONAL — see src/tiktokProvider.js
Real file downloads (blob + expiry / size / type checks, direct-open fallback)FUNCTIONAL
Demo sample mode (explicit button, labeled, never passed off as TikTok)FUNCTIONAL
Server-side key proxy / custom Node backendNOT NEEDED — providers used here require no secret; a Node outline is in src/README.md
Private / login-walled / removed videosNOT RETRIEVABLE — reported as errors by design

STACK: PERCHANCE NATIVE (main.pjs + index.html + src/ ES MODULES) — mirrors the React/Vite spec 1:1: Header · Hero · DownloaderForm · VideoResult · DownloadOptions · HowItWorks · StatusBar · Footer. No build step, no secret in browser code.

P PRIVACY

PRIVACY NOTICE

Links you paste are sent to the lookup provider to resolve that video — nothing else. We do not keep a history of your links on any server, we set no tracking cookies, and there are no accounts. Provider responses (thumbnails, CDN file URLs) expire; re-fetch if a download goes stale. Demo mode never leaves your browser.

T TERMS

USAGE TERMS

Download only videos you own or have explicit permission to save. Respect copyright, privacy, performer rights and TikTok's Terms of Service. Private, deleted, age-gated or region-blocked videos will fail — that is intentional. Do not use this tool to re-upload other people's work without consent, and do not use it to harass or dox anyone.

C CONTACT
